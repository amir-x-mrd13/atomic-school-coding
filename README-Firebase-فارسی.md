# راه‌اندازی سامانه تکالیف مدرسه انرژی اتمی

این نسخه، سایت فعلی را نگه می‌دارد و صفحه «ارسال تکلیف» و پنل استاد را اضافه می‌کند. دانش‌آموز می‌تواند نام، عنوان، متن و یک فایل تا ۱۰ مگابایت بفرستد. استاد مجاز می‌تواند تکالیف را ببیند، فایل را باز کند و نمره/بازخورد ذخیره کند.

## ۱) تنظیم پروژه Firebase
1. در https://console.firebase.google.com یک پروژه بسازید.
2. در Project settings > Your apps یک Web App اضافه کنید و تنظیمات عمومی آن را داخل `firebase-config.js` جایگزین کنید. مقدارهای `PASTE_...` نباید باقی بمانند.
3. در Authentication > Sign-in method، **Anonymous** و **Email/Password** را فعال کنید.
4. در Authentication > Users، یک کاربر استاد با ایمیل `amir.mrd186@gmail.com` بسازید و برای آن رمز قوی تعیین کنید. برای حساب استاد، ایمیل را تأیید کنید؛ قواعد فعلی فقط همین ایمیل تأییدشده را می‌پذیرد.
5. از Build > Firestore Database یک پایگاه داده بسازید.
6. از Build > Storage یک bucket بسازید.
7. در بخش Rules هر سرویس، محتوای `firestore.rules` و `storage.rules` را منتشر کنید. اگر Storage برای پروژه شما نیاز به طرح پرداخت فعال دارد، صفحه Firebase شرایط فعلی پروژه را نشان می‌دهد.
8. همه فایل‌ها و پوشه‌ها را در ریشه مخزن GitHub Pages بارگذاری کنید؛ `index.html`, `assignments.html`, `admin.html`, `firebase-config.js` باید کنار هم باشند.

## ۲) آدرس‌ها پس از انتشار
- سایت اصلی: `/`
- ارسال تکلیف: `/assignments.html`
- پنل استاد: `/admin.html`

## ۳) نکات امنیتی
- رمز پنج‌رقمی صفحه شروع قدیمی فقط یک دروازه ظاهری است و امنیت محسوب نمی‌شود. امنیت واقعی پنل استاد از Firebase Authentication و قوانین سرویس‌ها می‌آید.
- قوانین نمونه فعلاً فقط `amir.mrd186@gmail.com` را استاد می‌شناسند. برای تغییر ایمیل استاد، هر دو فایل `firestore.rules` و `storage.rules` را تغییر دهید و دوباره Publish کنید.
- این نسخه برای شروع، دانش‌آموزان را با ورود ناشناس Firebase ثبت می‌کند؛ هویت و اسم تایپ‌شدهٔ دانش‌آموز به‌تنهایی تأییدشده نیست. اگر نیاز به اثبات هویت دارید، ورود جداگانه دانش‌آموزان لازم است.
- قبل از استفاده واقعی، با یک حساب دانش‌آموز آزمایشی و حساب استاد، ارسال متن، ارسال فایل، مشاهده، نمره‌دهی و رد شدن دسترسی دانش‌آموز به پنل را آزمایش کنید.
- برای فایل‌های خیلی حساس یا استفاده گسترده، قواعد و محدودیت‌های ضداسپم را پیش از انتشار نهایی با فرد آشنا به Firebase بازبینی کنید.


## گزارش تلاش برای ورود به مدیریت
در این نسخه، هنگام ارسال فرم ورود مدیریت، نامی که فرد وارد کرده (اختیاری)، زمان، نوع تقریبی دستگاه و مشخصات مرورگر در مجموعه `managementAccessLogs` ثبت می‌شود و فقط استاد مجاز می‌تواند گزارش‌ها را ببیند. برای کارکردن این قابلیت، قواعد به‌روزشده‌ی `firestore.rules` را دوباره در Firebase منتشر کنید.

**محدودیت مهم:** این گزارش شماره/نام واقعی رایانه یا هویت قطعی دانش‌آموز را کشف نمی‌کند؛ اطلاعات دستگاه از مرورگر می‌آید و می‌تواند تغییر کند. همچنین گزارش‌گیری سمت مرورگر قابل جعل است. رمز یا کد واردشده عمداً ذخیره نمی‌شود. ورود امن استاد همچنان به Firebase Authentication وابسته است؛ این گزارش جایگزین امنیت واقعی نیست.
