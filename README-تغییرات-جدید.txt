تغییرات این نسخه
- حذف لینک/ورود ترمینال از صفحه اصلی؛ دانش‌آموز کد را در VS Code می‌نویسد.
- ورود مهمان نام دانش‌آموز را می‌پرسد و به ارسال تکلیف می‌رود.
- ارسال تکلیف فقط کد متنی است، بدون بارگذاری فایل.
- پنل استاد بخش افزودن دسته‌بندی، انتشار کد و جدول تأیید تکالیف دارد.

پیش‌نیاز مهم: firebase-config.js هنوز دارای مقادیر نمونه است و باید با تنظیمات واقعی پروژه جایگزین شود. همچنین قواعد Firestore فعلی احتمالاً برای collectionهای assignmentCategories و teacherCodes نیازمند تنظیم امن هستند. برای امنیت واقعی، صرف رمز PIN داخل HTML کافی نیست؛ دسترسی استاد باید با Firebase Authentication یا بک‌اند امن محدود شود. این بسته به‌تنهایی در GitHub منتشر نمی‌شود؛ محتویات را در مخزن جایگزین و Commit کنید.
