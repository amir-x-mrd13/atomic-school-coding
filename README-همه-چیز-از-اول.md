# بستهٔ کامل سایت مدرسه انرژی اتمی ⚛️

این بسته یک‌جا شامل سایت اصلی و فایل‌های قبلی، ترمینال پایتون، صفحهٔ ارسال تکلیف و پنل مدیریت است.

## راه‌اندازی از صفر
1. از این ZIP استفاده کن و تمام فایل‌ها و پوشه‌ها را در ریشهٔ مخزن GitHub خودت آپلود کن؛ ساختار پوشه‌ها را حفظ کن.
2. در GitHub، بخش Settings → Pages را باز کن و انتشار از شاخهٔ اصلی (معمولاً `main`, پوشهٔ `/root`) را تنظیم کن.
3. فایل `firebase-config.js` را با تنظیمات پروژهٔ Firebase خودت کامل کن.
4. Authentication و روش ورود Email/Password را در Firebase فعال کن و حساب استاد را بساز.
5. قوانین `firestore.rules` و `storage.rules` را منتشر کن.
6. پس از انتشار، صفحهٔ اصلی سایت لینک «ورود به ترمینال» دارد و فایل `terminal.html` هم جداگانه قابل باز شدن است.

## توجه‌های مهم
- بخش تکالیف و پنل مدیریت بدون تنظیم Firebase کار کامل نمی‌کند.
- گزارش تلاش ورود، نامی را که کاربر وارد می‌کند و مشخصات تقریبی مرورگر/دستگاه را ثبت می‌کند؛ هویت واقعی یا شمارهٔ دقیق رایانه را تضمین نمی‌کند.
- کدهای ترمینال با Pyodide داخل مرورگر اجرا می‌شوند و به‌صورت خودکار ذخیره یا برای استاد ارسال نمی‌شوند.
- رمز ورود مدیریت را داخل فایل‌های عمومی سایت قرار نده؛ احراز هویت Firebase و قوانین سمت سرور را نگه دار.
